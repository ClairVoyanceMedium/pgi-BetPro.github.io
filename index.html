📖 Installation
Mise en place en 15 minutes.
Secrets Cloudflare — toutes les variables
wrangler secret put AUTH_PASSWORD         # PgiBetProWinMoney (ou personnalisé)
wrangler secret put ODDS_API_KEY          # Clé 1 principale
wrangler secret put ODDS_API_KEY_2        # Clé 2 rotation auto
wrangler secret put ODDS_API_KEY_3        # Clé 3 rotation auto
wrangler secret put ODDS_API_KEY_4        # Clé 4 rotation auto
wrangler secret put ODDS_API_KEY_5        # Clé 5 rotation auto
wrangler secret put ODDS_API_KEY_6        # Clé 6 rotation auto
wrangler secret put AI_PROVIDER           # groq | gemini | anthropic | openrouter
wrangler secret put AI_API_KEY            # clé du fournisseur IA
wrangler secret put AI_MODEL              # optionnel (défaut auto selon provider)
wrangler secret put API_FOOTBALL_KEY      # optionnel — scores live football
wrangler secret put RESEND_API_KEY        # optionnel — alertes email
wrangler secret put EMAIL_TO              # optionnel — votre email
wrangler secret put EMAIL_FROM            # optionnel — expéditeur (ex: alerts@betpro.app)
Déployer
npm install -g wrangler
wrangler login
wrangler kv:namespace create BETTING_KV
# Ajoutez l'ID KV dans wrangler.toml :
# [[kv_namespaces]]
# binding = "BETTING_KV"
# id = "VOTRE_ID_KV"
wrangler deploy
