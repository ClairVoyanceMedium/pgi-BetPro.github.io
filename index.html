Installation
Mise en place en 5 étapes — environ 15 minutes.
0 — Configurer ce fichier (une seule fois)
Ouvrez index.html, cherchez la section CONFIG dans le <script> et remplacez les deux valeurs :
const WORKER_URL = 'https://bet-analyzer.YOURNAME.workers.dev';
const AUTH_TOKEN = 'votre_mot_de_passe';
1 — Installer Wrangler
npm install -g wrangler
wrangler login
mkdir bet-analyzer && cd bet-analyzer   # copier worker.js ici
2 — KV Namespace + wrangler.toml
wrangler kv:namespace create BETTING_KV   # copier l'ID retourné
name = "bet-analyzer"
main = "worker.js"
compatibility_date = "2024-01-01"

[[kv_namespaces]]
binding = "BETTING_KV"
id = "COLLER_VOTRE_KV_ID_ICI"

[triggers]
crons = ["0 7 * * *", "0 13 * * *", "0 19 * * *"]
3 — Secrets Cloudflare (clés API)
wrangler secret put AUTH_PASSWORD       # votre mot de passe de connexion
wrangler secret put API_FOOTBALL_KEY    # api-football.com → 100 req/jour gratuit
wrangler secret put ODDS_API_KEY        # the-odds-api.com → 500 crédits/mois gratuit
wrangler secret put ANTHROPIC_API_KEY   # anthropic.com → pour l'IA profonde
wrangler secret put RESEND_API_KEY      # resend.com → emails (3000/mois gratuit)
wrangler secret put EMAIL_TO            # votre adresse email destination
wrangler secret put EMAIL_FROM          # ex: alerts@votredomaine.com
4 — Déployer + GitHub Pages
wrangler deploy   # → https://bet-analyzer.YOURNAME.workers.dev
  • Créez un repo GitHub (ex: betpro)
  • Uploadez index.html à la racine
  • Settings → Pages → Source: branche main → Save
Sécurité : remplacez '*' par votre URL GitHub Pages dans CORS_ORIGIN (ligne 1 de worker.js) puis redéployez.
